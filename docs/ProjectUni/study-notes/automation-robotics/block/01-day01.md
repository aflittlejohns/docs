### Actuators
heater, buzzer, light are also considered as actuators.

### Transfer function

$G=output/input$

Relationship between output and input is the transfer function, in the units of the inputs and outputs.

For a temperature control

degrees centigrade input / I (current output for the steam valve)


flowchart LR
    A((e))
        B[C]
        C[G]
        d[S]
        input
        output
        input --> A
        A --> B
        B --> C
        C --> output
        C --> d
        d --> A

where ;
- e is the error
- C in the controller
- G is the process
- S is the feedback sensor
