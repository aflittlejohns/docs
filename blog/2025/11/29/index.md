##  Build Navigation docks

### Intro
There are two docked views, the north dock and the west dock.

The north dock is the traditional header which displays general information;

- the current date and time,
- Name of screen being viewed
- Log-in widget
- Status indicators
- Premierfoods Brand Logo

The west dock contains;

- navigation menu tree
- Operational (Phase) Status Icons

### Progress
Both docked views built with functioning tag references.

Menu tree in west view can be extended further if required.
